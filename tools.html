Programmatic Scanning

Scan from your own tools.

Example cURL and Python requests for integrating a scan into your workflow. The endpoint shown below has not been verified as a live public API.

Developer preview

Example request

Endpoint availability not verified
curl -X POST "https://api.africalatency.dev/v1/scan/public" \
  -H "Content-Type: application/json" \
  -d '{"target":"https://yourwebsite.com","region":"nairobi"}'import requests

response = requests.post(
    "https://api.africalatency.dev/v1/scan/public",
    json={"target": "https://yourwebsite.com", "region": "lagos"},
)
print(response.json())

Illustrative request only. Confirm the route, authentication requirements, rate limits and response schema before production integration. Copying this example does not run a scan.

Integration checklist
  • Confirm endpoint availability and supported HTTP method.
  • Validate request fields and the response schema against the deployed API.
  • Handle timeouts, unavailable probes and non-success HTTP responses.
  • Do not interpret illustrative values as live measurements.
