Why Africa isn't one network

The same service can feel different from one network to another.

Country, ISP, routing, cloud region and edge coverage can all change the path a request takes. We measure what is observable instead of assuming every location behaves the same.

Routing varies

Traffic may take different paths between ISPs, exchange points and your service.

Infrastructure varies

Origin region, DNS answers and CDN or edge coverage affect connection and response time.

Evidence matters

Probe availability changes. We report completed measurements separately from locations that returned no result.

What the audit covers

A clear public-endpoint performance baseline.

The standard audit tests public websites and API endpoints. It does not claim direct access to your private infrastructure.

  • DNS — lookup timing and returned resolution evidence
  • Connection and TLS — connection setup and handshake timing when available
  • HTTP response — time to first byte, total response timing and status
  • Network path — route evidence and hop information when returned
  • Location comparison — compare only locations that returned live measurements
  • Prioritized next steps — practical recommendations with limitations stated
