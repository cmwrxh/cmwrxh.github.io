Privacy and accuracy

What we record

If the test result can be saved, we retain measurements and resolved network metadata only. We do not persist raw IP addresses. For ASN/country lookup, the request IP is currently sent server-side to ipapi.co; this third-party processing should be disclosed in the privacy notice before public launch. Network type is labelled mobile only when the browser explicitly reports cellular or the network is identified as a known mobile operator. Otherwise, we call it “this device’s connection.”
